## 截图要求

1. 截图里不要出现任何真实 Key、Token、环境变量值（`.env` 内容不要截进去）。
2. 场景一的提问原文：
   ```
   我在红莲南路地铁站附近，我想要去一个既有倍轻松又有西厅村屋的离得近的商场，帮我推荐。
   ```
3. 场景二的追问原文：
   ```
   如果不要求两个品牌同时存在，还有没有距离更近的选择？
   ```
4. 提交前确认 `public-entry.txt` 里的地址在**不启动本地服务**的情况下也能打开。
